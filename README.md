These Files contain ANSYS Maxwell supported file to run basic analysis of following subjects 

"Ampere's Law"  - Models a conductor with excitation. Field calculator includes calculation for finding the closed integral of H around a point. 

"Magnet operating Point" - Magnetic circuit with excitation that includes a permanent magnet to find the operating point of a magnet. 

"Permanent Magnet Demagnetization" - Magnetic circuit with permanent to study the effect of demagnetization due to externally applied magnetic field.
